# 你装的社区版 vs 官方原版（2026-11-22 核对）

## 身份

| 项 | 你的手机 | 上游官方 |
|---|---|---|
| 仓库 | `puppy-bai/dsh-Go`（社区 Fork，基线上游 **v1.0.13**） | `ccch1mneyyy/dsh-Go` |
| 版本 | 1.0.19 (11161442)，2026-11-16 发布，**候选版** | 1.3.0 (11210245)，2026-11-20 发布 |
| 签名 | **Android Debug 证书** `48175d40 29e9d47c 4b008f15 f706cb4d eca1b88f 80095b14 d2b21a3d 4ed02d35` | 作者正式发布证书 |
| 更新器指向 | `const updateRepo = 'puppy-bai/dsh-Go'` | `'ccch1mneyyy/dsh-go'` |
| 维护状态 | 11-16 之后无提交、无新 release | 持续发版，29.7k star |

**结论**：二创（社区 Fork），不是原版。包名和关于页社交链接沿用上游，所以乍看像原版。
App 里点「检查更新」显示"已是最新"是真的——因为源码里更新仓库被改成了它自己。

## 它加了什么（相对基线 v1.0.13）

### 1.0.15 — 坐标操作
- 按文字点击、坐标手势、坐标输入
- 等待、连续滚动

### 1.0.16 — `run` 批量工具（第 16 个手机工具）
- 单应用一次最多 60 步，整批参数预检
- 每步重新读屏、文字定位，前后台包名守卫
- 失败给进度，不自动重放写操作
- 附手机任务技能、30 项场景分析、本地测试页

### 1.0.17 — 自动任务系统
- `schema:1` 本地自动任务 + `task` 工具：参数校验、条件分支、有限循环、等待、跨应用执行、受限 AI 检查点
- 自动任务页：提案审核、跑一次、保存后参数化复用、逐次确认、单任务长期授权、全局自动模式（重启保留）
- 暂停 / 继续 / 停止，累计最多两轮修复
- 可选本机截图证据（默认关，最多 10 张 / 50MB / 7 天）

### 1.0.18 — 修 bug
- 修 Android 正则不接受结尾花括号，导致任务解析器初始化失败、界面露出混淆类名 `i5`

### 1.0.19 — 候选版
- 普通聊天 `run` 加 `schema:2`：声明应用范围、选择器、等待、查找、`if`、有限 `repeat`、`yield`
- 执行段内可用截图坐标点击 / 输入 / 手势，每次动作后交回原会话判断，旧坐标失效
- `send:{app,recipient,text}` 发送范围授权，同一手机任务内跨步骤复用
- 首次按应用确认视觉权限，可在应用名单撤销
- **作者自述：本候选版人工真机验收尚未进行**

## 没被改的部分（核对过）

- `update_config.dart` 除 `updateRepo` 一行外与上游完全一致
- Android 权限与上游 1.3.0 基本相同（官方多了 `CAMERA`，因为 1.3.0 加了拍照）
- 包名、关于页社交链接、AGENTS.md 体系、runtime 补丁机制都是上游那套

## 风险点（按轻重排）

1. **Debug 证书签名**。作者注明"保留是为了升级兼容"。Debug 密钥不是发布密钥，一旦证书文件被共享或泄露，别人能签出同签名包覆盖你的 App——系统签名校验会通过，只剩安装弹窗这一道。正式发布版用的是作者私有发布证书。
2. **永远收不到官方更新**。更新器写死了社区仓库，官方 1.0.14 → 1.3.0 的所有修复和功能（语音通话、酒馆玩法包、后台保护、使用统计 v3、会话搜索增强…）这条线拿不到。
3. **停更在 11-16**。基线 v1.0.13 已落后上游三个大版本，中间上游修过的问题它都没有。
4. **1.0.19 是未验收的候选版**，作者自己写"人工真机验收尚未进行"。
5. **能力放大**。坐标点击、批量任务、跨步骤发送授权复用，让 AI 一次能干的事更多；误操作的影响面也同比放大。这台手机上已经授权了完全权限 + 无障碍 + 手机操控。

## 两条路的实际差别

| | 留社区版 | 换官方 1.3.0 |
|---|---|---|
| 数据 | 不动 | 必须卸载重装，靠备份恢复 |
| 手机操控 | 坐标手势、`run` 多步、自动任务页 | 悬浮条、不打扰模式、确认三档；无坐标手势/自动任务页 |
| 语音 | 无 | 朗读、语音输入、语音通话 |
| 酒馆 | 旧版功能 | 玩法包、做卡工具、导入网页对话 |
| 后续更新 | 基本没有 | 走官方通道，同签名可覆盖升级，数据保留 |
| 签名安全 | Debug 证书 | 发布证书 |
